# 구글 시트 백엔드 — 통째로 바꾸는 파일

`Code.gs` 하나가 전부입니다. 조각을 찾아 넣으실 필요 없습니다.

## 바꾸는 법

1. Apps Script 편집기를 엽니다
2. **기존 내용을 전부 지웁니다**
3. `Code.gs`를 통째로 붙여넣습니다
4. **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**

저장만 해서는 반영되지 않습니다. 배포 주소(`/exec`)는 그대로입니다.

## 되돌리기

Apps Script는 이전 코드를 스스로 보관합니다.

- **배포 관리**에서 이전 버전을 고르면 즉시 되돌아갑니다
- 편집기 **파일 → 버전 기록**에도 예전 코드가 남아 있습니다

붙여넣기 전에 기존 코드를 따로 복사해 두시면 더 안전합니다.

## 확인하는 법

배포한 뒤 `/exec` 주소 뒤에 아래를 붙여 브라우저에서 열어 보세요.

| 주소 | 정상일 때 |
|---|---|
| `?tops=1` | `{"tops":[]}` — 아직 승인한 사람이 없다는 뜻 |
| `?load=독코(Dokko)` | `{"found":true,...}` 또는 `{"found":false}` |
| (아무것도 안 붙임) | `{"week":[...],"schools":{...},"recent":[...]}` |

`?tops=1`인데 주간순위가 나오면 **새 버전 배포가 안 된 것**입니다.

## 시트 이름은 이제 자동으로 찾습니다

첫 칸(A1)이 **`시각`**인 시트를 활동기록으로 봅니다. 이름이 `기록`이든
`활동기록`이든 상관없고, **여러 개면 전부 합쳐서** 읽습니다. 예전에 다른
이름으로 쌓인 기록도 한 줄도 빠지지 않습니다.

새로 쌓이는 기록은 **줄이 가장 많은 시트**, 즉 지금까지 써 오던 시트에
이어 붙습니다.

## 명예의 전당이 '불러오지 못했습니다'로 뜰 때

응답이 8초 안에 오지 않아 브라우저가 끊은 것입니다. 이 파일에서 고쳤습니다.

- 줄마다 날짜를 변환하던 느린 부분을 계산식으로 바꿨습니다
- 집계 결과를 **60초 동안 보관**해 두고 재사용합니다
- 최근 8,000줄만 훑습니다 (기록이 수만 줄로 늘어도 느려지지 않습니다)

그래도 안 되면 `/exec` 주소를 브라우저에서 그냥 열어 보세요. 몇 초 만에
`{"week":[...]}`가 나오면 정상입니다. 로그인 화면이 나오면 **배포 설정의
'액세스 권한'이 '모든 사용자'가 아닌 것**이니 그 부분을 바꿔 주세요.

## 예전 시트 이름 확인

파일 위쪽에 이 줄이 있습니다.

```javascript
var LOG_SHEET  = '활동기록';
```

지금 쓰시는 활동기록 시트 이름이 다르면 **따옴표 안만** 실제 이름으로 바꿔
주세요. `saves`와 `tops` 시트는 없으면 자동으로 만들어집니다.

## 최고 단계 도달자 승인

`tops` 시트에 이렇게 쌓입니다.

| 별명 | 단계 | 정답수 | 도달시각 | 승인 | 승인시각 |
|---|---|---|---|---|---|

**`승인` 칸에 `예`를 적으면** 그 사람만 전체 화면 배너에 나갑니다.
비워 두면 아무에게도 보이지 않습니다. 지우면 다시 숨겨집니다.

정답수는 시트에만 남고 밖으로 내보내지 않습니다. 주소가 공개돼 있기 때문입니다.

## 이 파일에 들어 있지 않은 것

바다 실측 기온을 받아오는 기능(KHOA)은 지금 **꺼져 있고 따로 관리**합니다.
서비스 키가 필요해서 이 파일에 섞지 않았습니다. 켜실 생각이 있으실 때 따로
말씀해 주시면 그때 정리해 드리겠습니다. 지금 상태로도 화면의 날씨 효과는
정상 동작합니다.

## 파일을 못 여는 분에게 기록 넘기는 법

`.json` 파일은 **읽는 파일이 아니라 앱이 삼키는 파일**입니다. 캡처 이미지나
PDF로 바꾸면 복원이 안 됩니다. 확장자를 `.txt`로 바꾸는 것도 안 됩니다 —
앱의 파일 선택창이 `.json`만 받습니다.

파일을 다루기 어려워하시는 분께는 **파일을 아예 보내지 마세요.** 대신 교수님이
대신 올려두고, 그분은 별명만 입력하시면 됩니다.

**교수님이 하실 일 (한 번)**

1. 브라우저 **시크릿 창**을 엽니다 (교수님 본인 기록이 섞이지 않게)
2. 사이트를 열고 **기록 → 백업 파일 불러오기**로 그분의 `.json`을 넣습니다
3. **기록 → 다른 기기에 저장**에서 그분의 **별명**으로 저장합니다
4. 시크릿 창을 닫습니다

**그분이 하실 일**

사이트를 열고 → 별명 입력 → **불러오기**. 끝입니다. 파일도, 앱 설치도 없습니다.

기록이 길면 자동으로 여러 칸에 나눠 저장되고 불러올 때 다시 이어 붙습니다.
가장 긴 기록(603문항·정답 2,619)으로 확인했습니다.

## 알아두실 점

- **학교별 순위는 `학교부문`(E/M/H/W) 칸이 채워진 기록만 집계합니다.** 지금까지
  쌓인 기록에는 이 칸이 비어 있어 학교 순위가 비어 보입니다. 앞으로 쌓이는
  기록에는 앱이 이 값을 함께 보내므로 점차 채워집니다.
- 주간 순위는 **월요일 기준**으로 이번 주 것만 셉니다.
- 이 주소는 공개되어 있어 누구나 호출할 수 있습니다. 별명만 알면 그 사람의
  학습 진도를 불러올 수 있다는 뜻입니다. 이름·나이는 저장하지 않습니다.
