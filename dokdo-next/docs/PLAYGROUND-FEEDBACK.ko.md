# 음악·게임 반응 보완 · 2026-10-19

이전 로컬 작업의 음악·게임 피드백 변경만 최신 운영 코드에 선택 반영했습니다. 계정·인증 설정, 점수 엔진, 도전권·섬 성장 규칙, 원장, 공유 정보는 이 작업에서 변경하지 않습니다.

## 실제 변경

- 배움터와 놀이터의 음악 재생 요청에 순서 번호를 적용합니다. 다음 곡 연타나 켜기·끄기·다시 켜기가 겹쳐도 이전 요청의 늦은 성공·실패가 새 재생을 멈추지 않습니다. 끈 뒤 늦게 발생한 재생 이벤트도 음소거·정지합니다.
- 같은 곡을 다시 켤 때 음원 주소를 재지정하지 않아 기존 재생 위치를 유지합니다. 실제 음악 재생 객체는 명시적으로 음악을 켠 뒤 만들며, 만든 객체는 미리 읽기를 허용합니다. 음악이 꺼져 있을 때 곡 종료 이벤트가 다시 켜지 않도록 합니다.
- 게임 효과음은 배경 음악과 분리합니다. 놀이 시작·재개 또는 효과음 켜기의 사용자 동작에서 하나의 효과음 컨텍스트를 준비합니다. 효과음 켜기·끄기는 음악 파일·재생 위치를 건드리지 않습니다. 동시 효과음은 12개로 제한하고 종료·예외 시 노드를 정리합니다.
- 바다 청소에서 사라진 칸의 쓰레기를 잠깐 띄우고 파문을 표시합니다. 망치 제거·강치 구조·미션 성공에 서로 맞는 짧은 반응을 줍니다. 미션 완료 후에도 청소한 판을 볼 수 있으며 블록 트레이는 숨깁니다.
- 달리기에서 별 획득, 장애물 통과, 충돌, 라운드 완주에 다른 반응을 줍니다. 같은 프레임에 별 두 개를 얻으면 `+2`로 표시합니다. 실제 점수와 충돌 판정은 기존 엔진 그대로입니다.
- 효과는 화면 전체를 흔들지 않는 별도 층에 표시하며 입력을 가로막지 않습니다. 한 곳의 효과 요소와 타이머를 최대 48개로 제한하고 종료·페이지 이탈 때 정리합니다. OS와 앱의 움직임 줄이기를 따르며, 이 경우 입자 대신 짧은 문구만 남깁니다. 새 효과음 상태와 반응 문구는 한국어·영어를 지원합니다.
- 게임 중 중간 저장은 숨겨진 섬과 선물 목록을 매번 다시 만들지 않습니다. 저장·보상 계산은 계속 실행하며 게임 종료·화면 복귀 시 섬을 갱신합니다. 새 선물 안내는 미션 완료나 게임 결과에서 보여 주어 진행 중인 배치를 끊지 않습니다.
- 선물 카드와 스크린리더 안내는 새 정원 성장 순서를 한국어·영어로 설명하고 실제 개수를 표시합니다. 예전 불빛은 기존 보유자에게만 표시하며 완성과 새 선물 판단은 실제 해금 조건을 사용합니다. 언어를 바꿀 때 현재 바다 상태 문구만 새 언어로 바꾸고 게임판은 재생성하지 않습니다.
- 미션별 수중 배경은 별도 아트 함수 `blockHabitat`와 `habitatName`을 보드와 상태 안내에 연결합니다. 배경 캔버스는 64개 입력 셀과 구분하며 저장 데이터를 바꾸지 않습니다. 배경 그림·크기·카드 글자 조정은 부모 작업의 별도 변경입니다.

## 검사와 범위

`tests/audio-feedback.test.cjs`는 실제 화면 처리 함수를 격리 어댑터에서 실행합니다. 음악 요청 순서 역전, 닫은 뒤 늦은 재생, 동일 곡 위치 보존, 효과음 분리·상한·실패 정리, 쓰레기 제거·구조·달리기 반응, 두 별 동시 획득, 효과 정리·움직임 줄이기, 배경과 셀의 분리, 언어 상태를 검사합니다. 새 1·2단계는 실제 배치 함수로 각각 6번 놓은 뒤 16·24칸을 지울 때 성공 반응이 나오는지 확인하며, 예전 8칸 판은 별도 이전 기록 예제로 보존합니다.

`tests/audio-feedback-browser.py`는 별도 로컬 서버·새 브라우저 컨텍스트·가상 게임 기록을 사용합니다. 운영 기록지·분석 설정을 비우고 외부 요청을 차단합니다. 실제 HTMLAudioElement의 시간 증가·다시 불러오기 횟수·정지 상태와 효과 표시를 검증하며, 계정 가입이나 메일을 시험하지 않습니다. Chromium·WebKit을 선택할 수 있고 검사 결과를 별도 폴더로 저장합니다.

브라우저 검사는 실행 환경에 Playwright와 해당 브라우저가 필요합니다. 단위검사 통과만으로 실제 스피커 청취나 모든 기기에서의 무중단 재생을 확인했다고 하지 않습니다. 외부 네트워크·기기 버퍼링으로 생기는 끊김까지 보장하지 않으며, 운영 배포와 실제 화면·청취 확인은 통합 검수에서 별도로 진행합니다.
