# 한국어·미국식 영어 — V3

운영본 메인·배움터·놀이터·계정에서 한국어/영어를 선택합니다. 공통 UI 선호 키 dokdo-ui-language-v1만 읽고 저장합니다. 미리보기·데모는 해당 키에 접근하지 않습니다. 계정 토큰·학생 기록은 언어 모듈이 읽지 않으며 신규 외부 요청도 없습니다. 기존 학습 화면의 언어 저장과 번역을 유지하고 이동 시 공통 선택을 우선합니다.

놀이터의 고정 UI·미션·결과·ARIA·계정 오류 문구는 로컬 사전으로 번역합니다. 글자 노드·라벨별 한국어 원문을 보존해 왕복 전환합니다. 폼 value·계정 이메일/비밀번호를 번역하거나 수집하지 않습니다. 도전권 문제는 기존 authored course-data 영어 원문을 그대로 사용하며, 음악은 기존 tEn 제목을 표시합니다. 게임 캔버스의 지명은 언어를 따라 다시 그립니다. 메인의 기존 번역 소유권을 유지하고 누락 ARIA만 추가로 변환합니다.

별도 검수에서 접두어 조기 반환으로 남던 한국어, 실시간 안내, 메인 ARIA, 음악 제목, 움직임 줄이기 상태의 캔버스 갱신을 수정했습니다. 기존 영어 기초문항 589개 텍스트 조각에 변형이 없다는 독립 검수도 받았습니다. 실제 계정 메일 발송·비밀번호 변경 기능은 이번 번역에서 변경하지 않습니다.

반영 전 태그: before-bilingual-v3-20261019 (a440ee7). 되돌림은 이 언어 PR을 revert하는 별도 PR로 검사하며 UI 선호 키는 학습·게임·계정 기록에 영향 없이 남겨 둘 수 있습니다.
