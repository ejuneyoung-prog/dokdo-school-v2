# 놀이터와 나의 독도 · 2026-10-19 수정

배움터만 반영되고 놀이터가 빠진 누락을 바로잡는 변경이다. 운영 URL·공유 메타 정보·QR·240문항·학습 XP/학년·공개 순위 규칙·계정 권한은 바꾸지 않는다.

## 몰입을 위한 실제 변경

몰입의 도전과 실력의 균형은 [칙센트미하이의 소속 대학 설명](https://www.cgu.edu/news/2000/09/mihaly-csikszentmihalyi-flow/)을 참고했다. 아래 수치는 이번 게임을 위한 설계 판단이며, 사용자 몰입을 실험으로 입증했다는 뜻은 아니다.

| 조건 | 화면과 동작 |
| --- | --- |
| 분명한 목표 | 청소한 칸/목표, 남은 5분, 구조·연속 청소 조건을 표시한다. |
| 적절한 도전 | 새 1단계는 최소 6회 배치·16칸/2줄, 2단계는 최소 6회·24칸/3줄이다. 첫 움직임만으로 끝나지 않는다. 초반 다음 블록은 무작위 불운으로 즉시 막히지 않게 한다. |
| 즉각적인 반응 | 쓰레기 제거·구조·달리기 별/충돌/완주 효과를 구분한다. 청소 진행에 따라 물이 맑아지고 클리어 때 환해진다. 짧은 효과음과 음악은 독립 제어한다. |
| 통제감 | 일시정지·보관·이어하기, 블록 힌트, 달리기 점프 높이 조절을 유지한다. 다음 단계는 사용자가 누른 뒤 시작한다. |
| 집중 | 플레이 중 뒤에 가려진 섬을 계속 다시 만들지 않는다. 전체 화면 흔들림·번쩍임을 쓰지 않고 모션 감소 설정을 따른다. |

수중 배경은 독도 수면 아래·바위 아래·깊고 푸른 바다 순으로 바뀐다. 실제 측량도나 현재 생태 촬영을 재현한 것이 아닌 창작 게임 풍경이다.

## 하나의 섬, 활동에 따라 다른 색

- 정답 보상을 받은 새 개념마다 해국 1송이, 최대 100송이. 같은 개념의 당일 중복 보상은 기존 제한을 따른다. 기존 유효 학습 기록의 불빛 수도 검증된 학습 모델에서 읽어 해국 성취로 보존한다.
- 달리기의 실제 누적 점수 20점마다 잔디 한 곳, 최대 100곳. 같은 체크포인트 재전송·이전 점수·완료 재호출은 잔디를 중복 지급하지 않는다. 기존 누적 원본이 없는 기록은 기존 최고 달리기 점수까지만 보존하고 과거 전체 합계를 추측하지 않는다.
- 해국 100과 잔디 100을 채운 뒤 사철나무 → 새우 → 괭이갈매기 → 강치 → 마지막 별로 넓힌다. 나무·새우·갈매기는 각각 최대 10개이며 꾸미기 XP 100점 단위로 늘어난다. 나무는 XP 1,000까지, 새우는 1,000 이후 2,000까지, 갈매기는 2,000 이후 3,000까지이다.
- 선행 정원을 채운 뒤 10단계 이상의 청소 미션/달리기 라운드를 완주할 때 강치가 한 마리씩 늘어난다. 강치 최대 10마리와 20단계를 모두 달성하면 마지막 별이 열린다. 경비대·삽살개·깃발은 하나씩만 등장한다.
- 기존에 획득했거나 꺼두었던 선물은 `gardenLegacy`로 보존한다. 예전에 완성의 별을 받은 사람은 완성 표시도 보존한다. 새 사용자의 해금과 그림·선물 설명·수량·완성 표시는 같은 `gardenPlan` 규칙을 사용한다.
- 가운데 물 위에 학습 불빛 점을 겹쳐 찍던 연출은 없앴다. 해국/잔디는 양쪽 섬에 50곳씩 총 100곳에 심는다. 삽살개는 동도 아래쪽 길을 천천히 걷고 모션 감소 설정에서는 정지한다.

`quizFlowers`, `runnerScore`, `gardenVersion`, `gardenLegacy`는 기존 로컬 게임 기록의 선택 필드다. 개인 보관함의 허용 필드·이전 기록 덮어쓰기 방지에도 반영한다. 로그인이나 공개 범위를 확장하지 않는다.

## 자랑과 가독성

자랑하기는 사용자가 누르면 현재 섬을 `my-dokdo.png`로 저장한다. 닉네임·학교·계정 식별자·토큰을 넣거나 외부로 업로드하지 않는다. 사용자가 저장한 사진을 직접 공유한다.

놀이터의 작은 선물 그림까지 섬 캔버스의 최소 높이 200px를 상속하던 오류를 고친다. 본문/버튼은 기본 16px, 보조 문구 14px, 주요 조작 영역은 44px 이상이다. 선물은 넓은 카드로 바꾸고 모바일·영어·텍스트 확대에 맞춰 줄바꿈한다.

## 검사와 되돌림

단위·정적·문항 빌드, 실제 브라우저 조작, CI Chromium/WebKit 검사 결과는 이관팩의 검사 자료에 기록한다. 실제 스피커 음질·iPhone/Safari 실물 청취와 자동화의 MP3 재생 위치 검증은 구분한다.

기준: `before-playground-garden-20261019` (6aa3ebb). 구판 진행 중인 퍼즐은 `missionVersion:1`의 보드·목표·시간을 보존하며 새 판부터 version 2를 쓴다. 되돌릴 때는 새 기록 필드를 읽지 못하는 과거 버전을 바로 덮지 말고, 새 필드·v2 판을 계속 읽는 호환 리버트 PR로 화면 변경을 되돌린다. 사용자 기록은 삭제하지 않는다.
