# 강치 돌아오는 길 — 만들기 사양서

독도 코리아 스쿨에 붙일 작은 게임의 사양이다. 이 문서만 보고 만들 수 있게 썼다.

---

## 1. 무엇을 만드나

멸종한 독도 강치가 **가제바위로 돌아오는** 옆으로 흐르는 게임.
조작은 한 손가락. 한 판 30~40초.

- 화면을 누르면 강치가 위로 솟구치고, 떼면 가라앉는다
- **물고기**를 먹으면 점수
- **그물**에 걸리면 먹은 물고기를 잃는다
- 끝까지 가면 **강치 한 마리가 가제바위에 자리를 잡는다**

## 2. 반드시 지킬 것

### 함정은 '그물'이다. 배가 아니다.

**일본 배·사람·국기를 적으로 두지 않는다.** 이 앱은 외교부·해양수산부 자료를
출처로 다는 교육 도구다. 아이가 특정 나라를 공격하는 화면이 있으면 앱이 쌓은
신뢰가 무너진다.

그물이 옳은 이유는 그게 **사실**이기 때문이다. 독도 강치를 없앤 것은 남획이다
(해양수산부 2022년 강치 연구). 폐그물은 지금도 바다 생물을 죽인다. 그물은
나라가 아니므로 아이에게 미워할 대상을 만들지 않는다.

### 난이도는 '쉽게'

**죽지 않는다.** 그물에 걸려도 먹은 물고기 일부를 잃고 계속 간다.
누구나 끝까지 도착한다. 이 게임의 목적은 실력 겨루기가 아니라
**강치를 돌려놓는 경험**이다. 실패로 끝나면 메시지가 반대로 간다.

### 없는 사실을 지어내지 않는다

강치·독도에 관한 문구는 **이미 있는 출처 안에서만** 쓴다. 새 사실, 새 숫자,
새 기관 이름을 만들지 않는다. 게임이 끝나고 보여 줄 한 줄은 이것으로 한다:

> 1904년 무분별한 남획으로 독도 강치는 사라졌습니다.
> 출처: 대한민국 해양수산부 · 독도 강치 연구 발표(2022)

물고기 종류에 이름을 붙이지 않는다. 그냥 '물고기'다. 독도 주변 어종을
확인 없이 적으면 틀린 정보가 된다.

## 3. 학습과 어떻게 묶이나

**5문제를 맞히면 1회 플레이가 열린다.** 공부해야 놀 수 있고, 놀면 또 공부하게
된다. 게임이 학습을 밀어내면 안 된다.

이미 같은 방식이 있다. `dokdo-core.js`의 강치 부르기가 그것이다:

- `s.gcHit` — 정답마다 쌓이는 값. 5가 모이면 강치 한 마리를 부를 수 있다
- `Core.invite(s, now, 요청수)` — 5씩 깎아서 강치를 자리에 앉힌다
- `s.gangchiVisits` — 지금 와 있는 강치들 (최대 10)
- `s.gcSummons` — 지금까지 부른 총 횟수

**게임도 이 값을 그대로 쓴다.** 새 통화를 만들지 말 것.

- 플레이 1회 = `gcHit` 5 소모
- 끝까지 도착 = `Core.invite(s, now, 1)`과 같은 결과 (강치 한 마리 자리잡음)
- 중간에 그만두면 소모한 것은 돌려주지 않는다 (한 번 부른 것으로 친다)

`gcHit`을 직접 빼지 말고 **기존 함수를 통해** 바꾼다. 상태를 바꿀 때는
`app.js`의 `mutate(s=>{...})`를 쓴다. 직접 `store.save()`를 부르지 않는다.

## 4. 어디에 붙이나

### 파일

새 파일 하나로 만든다. 기존 파일을 크게 건드리지 않는다.

```
assets/gangchi-run.js     ← 게임 전부 (새 파일)
index.html                ← 화면 한 칸과 <script defer> 한 줄 추가
assets/app.css            ← 게임 화면 모양
assets/app.js             ← 게임 열고 닫는 연결 몇 줄
```

`index.html`의 다른 `<section class="view">`들과 같은 방식으로 화면을 하나
추가한다. `app.js`의 `view(id)`가 화면을 바꾼다.

### 캔버스

기존 풍경은 `#island-canvas`(1536×704)를 쓴다. **게임은 자기 캔버스를 따로**
가진다. 풍경 그리기와 섞지 않는다.

세로 화면(휴대폰)에서 편해야 한다. 폭 360px에서 잘 되는지 반드시 본다.

### 움직임을 멈춰야 할 때

- 다른 화면으로 가면 멈춘다
- 탭이 뒤로 가면(`document.hidden`) 멈춘다
- 대화상자가 열리면 멈춘다
- `s.visual.reduceMotion`이 켜져 있거나 `prefers-reduced-motion`이면
  **흔들림·번쩍임을 빼고** 조용하게 움직인다. 게임 자체를 막지는 않는다

`app.js`의 `visible()`과 `reduced()`가 이미 같은 판단을 한다. 참고할 것.

## 5. 만들 때의 제약

### 밖에서 아무것도 받아오지 않는다

`index.html`의 CSP가 외부 스크립트를 막는다. **라이브러리를 쓰지 않는다.**
게임 엔진, 물리 엔진, 소리 라이브러리 전부 안 된다. 순수 캔버스 2D로 만든다.

이미지도 새로 받지 않는다. 강치·물고기는 **캔버스에 직접 그린다**.
기존 `assets/scene.js`가 물고기와 강치를 그리는 방식을 그대로 참고한다.

### 소리

기본은 꺼짐. 사용자가 켜야 난다. 자동 재생 금지.

### 기록을 건드리지 않는다

정답·XP·불빛·봉화를 게임으로 얻을 수 없다. 게임은 `gcHit`을 쓰고 강치를
앉히는 것까지만 한다. **문제를 풀지 않고 레벨이 오르면 안 된다.**

## 6. 다 만든 뒤 반드시 돌릴 것

```
cd dokdo-next
npm test                        # 157개 통과해야 함
python3 tools/check_site.py     # 86개 통과해야 함
python3 tests/release-13-browser.py --mode http
python3 tests/browser.py --mode http
python3 tests/clear-browser.py --phase screens --mode http
```

브라우저 검사에는 `--browser <크로미움 경로>`가 필요할 수 있다.

**특히 이 두 가지가 깨지기 쉽다:**

- `No production or weather calls under unconfigured mode` — 게임이 밖으로
  요청을 보내면 실패한다
- `no horizontal page overflow` — 게임 화면이 가로로 삐져나가면 실패한다

## 7. 완성으로 치는 기준

1. 휴대폰 세로(폭 360px)에서 한 손가락으로 끝까지 할 수 있다
2. 정답 5개가 없으면 시작할 수 없고, 왜 안 되는지 화면이 말해 준다
3. 도착하면 강치가 실제로 풍경에 자리잡는다 (새로고침해도 남아 있다)
4. 도착 화면에 남획 한 줄과 출처가 뜬다
5. 그물에 걸려도 게임이 끝나지 않는다
6. 다른 화면으로 가면 움직임이 멈춘다
7. 위 검사가 전부 통과한다

## 8. 하지 말 것 (요약)

- 일본 배·사람·국기를 적으로 두기
- 죽거나 게임 오버로 끝내기
- 출처 없는 사실·숫자·물고기 이름 쓰기
- 외부 라이브러리·이미지 가져오기
- 게임으로 정답수·XP·레벨 올리기
- `data/course-v2.json`, `assets/course-data.js` 직접 고치기
  (문항 원본은 `tools/content/authored-questions.json` 하나뿐이다)
