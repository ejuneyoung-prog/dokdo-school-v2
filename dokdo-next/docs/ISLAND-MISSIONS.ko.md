# 섬 성장·청소 미션 V3 — 2026-10-19

교수님 지시: 초보는 쉽게, 한 판 최대 5분, 10단계는 큰 고비·20단계는 더 어려움. 10단계부터 완료마다 강치 한 마리, 최대 10마리. 20단계와 강치 10마리에서 별. 경비대·삽살개는 하나, 다른 생물은 종류별 최대 10개. 주변 바위와 상상 강치바위, 태극기 바로 옆 작은 경비대원, 섬이 더 크게 보이도록 비율 조정.

## 진행 규칙

청소 목표(단계 1~20, 칸): 8,16,24,32,40,48,56,64,80,120,128,136,144,152,160,176,192,208,224,240.
1~9단계는 수거량, 10~19단계는 수거량+2회 연속 청소+강치 구조 1회, 20단계는 수거량+3회 연속 청소+구조 1회. 1~2단계는 작은 조각 위주, 3~5단계는 중간 조각, 이후는 전체 조각을 무작위로 사용합니다. 실제 이용자 완료율은 아직 측정하지 않았으므로 출시 후 10·20단계 이탈률로 조정해야 합니다.

한 판 안의 다음 미션은 누적 점수·잔여 시간·망치를 유지합니다. 완료 화면·일시정지·숨긴 탭은 시간에서 제외합니다. 새 판은 마지막 청소 성공 다음 단계부터 시작하고 시간은 5분, 도전권 1회를 씁니다. 획득 XP·강치·꾸밈은 실패해도 유지합니다. 청소 미션과 달리기 라운드는 같은 섬 성장에 반영합니다. XP→꾸미기 환산은 기존 floor(score/10)을 유지합니다. 학습 점수·공개 순위·Apps Script는 변경하지 않습니다.

- [Royal Match 공식 부스터 안내](https://dreamgames.helpshift.com/hc/en/3-royal-match/faq/8-using-boosters/?f=using-boosters&l=en&s=gameplay-guide): 한 칸을 제거하는 망치 참고. 강치 구조→망치는 이 게임의 자체 규칙입니다.
