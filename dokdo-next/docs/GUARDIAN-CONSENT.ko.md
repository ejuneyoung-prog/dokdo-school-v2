# 만 14세 미만 순위 참여: 보호자 메일 동의

나이대가 7세 이하, 8~9세, 10~11세, 12~13세이거나 나이대를 모르는 기기는 닉네임, 학교, 학습 기록을 서버로 보내지 않습니다. 기록은 그 기기에만 남습니다.

## 절차
1. 보호자가 officialdokdokorea@gmail.com으로 동의 요청 메일을 보냅니다.
2. 운영자가 받는 항목, 목적, 공개 범위, 보관 기간, 거부 방법을 적은 답장을 보냅니다.
3. 보호자가 동의한다는 회신을 보내면 시행령 제17조의2의 전자우편 방식으로 확인합니다. 회신 메일을 보관합니다.
4. `python3 tools/guardian_code.py`로 링크와 값을 만듭니다.
5. 값을 `assets/site-config.js`의 `guardianConsentHashes`에 넣어 배포합니다.
6. 링크를 보호자에게 보냅니다. 어린이가 쓰는 기기에서 한 번 열면 그 기기의 순위 참여가 열립니다.

## 철회
1. 값을 `guardianConsentHashes`에서 뺍니다. 새 기기에서는 링크가 듣지 않습니다.
2. 이미 열린 기기는 저장값 `dokdo-guardian-consent-v1`이 남으므로 시트의 기록을 지우고, 보호자에게 해당 기기의 사이트 데이터를 지우도록 안내합니다.

## 알아 둘 점
- 동의를 기기에 저장하므로 기기를 바꾸면 링크를 다시 열어야 합니다.
- 나이대는 본인이 고릅니다. 본인 인증이 아닙니다.
- 이 변경 전에 올라간 기록은 시트에 남아 있습니다. 삭제 여부는 교수님이 정합니다.
