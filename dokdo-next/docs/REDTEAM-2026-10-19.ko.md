# V3 출시 전 레드팀 · 2026-10-19

교수님 요청에 따라 학습·게임·통합을 세 담당자가 검토하고 발견 결함을 수정했습니다. 문항 원문·정답·기존 저장 키·순위 규칙·Apps Script는 수정하지 않았습니다.

## 확인하고 수정한 결함

1. P1 — 단일 미리보기가 운영 API·GA 설정을 포함해 학습 기록을 전송할 수 있었습니다. 명시적 live 모드에서만 통신하도록 모듈 경계를 막고, 생성 미리보기에서는 API·GA 설정도 비웁니다. 운영 서버로 시험 요청은 보내지 않았습니다.
2. P2 — 달리기의 전역 점프 키가 일시정지·뒤로·음악 버튼의 Space 입력을 가로챘습니다. 다른 버튼의 기본 키보드 동작을 유지합니다.
3. P2 — 블록 시간 계산이 프레임 지연을 250ms로 잘라 30초 제한이 늘어났습니다. 전면 화면 실제 경과시간을 반영하며 명시적 일시정지·다른 앱으로 이동한 시간은 기존처럼 제외합니다.
4. P2 — 도전권 퀴즈의 보기가 고정이었습니다. 표시 순서를 섞고 원래 정답·오답별 해설 인덱스를 보존합니다. 저장 중 답안 중복 입력과 교체된 문제에 이전 결과가 표시되는 경쟁도 막습니다.
5. P2 — 결과·학년·명예의 전당에서 언어를 바꿔도 동적 내용이 남았습니다. 결과는 메모리의 표시 입력만 재사용하고 명예의 전당은 마지막 응답을 재사용합니다. 재채점·경험치 재지급·순위 API 추가 조회 없이 번역합니다.
6. P2 — 이관팩 단일 미리보기 결과의 게임 링크가 없는 상대 파일로 향했습니다. 운영 독도놀이터를 새 창으로 열고 미리보기 보상과 구분해 안내합니다.
7. P3 — 음악 안내가 실제 백그라운드 재생 동작과 달랐습니다. 직접 끄거나 페이지를 떠날 때 종료된다는 현재 동작으로 안내를 맞췄습니다.

명칭 변경 PR에서는 별도로 WebKit의 768px 영문 헤더 넘침을 발견해 태블릿에서 두 줄로 배치했습니다. 학습은 독도배움터, 게임은 독도놀이터로 표시하며 기존 V2 주소에서 V3를 계속 제공합니다.
