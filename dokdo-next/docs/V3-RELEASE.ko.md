# 독도 코리아 스쿨 V3 · 2026-10-18

교수님 요청에 따라 ‘한 화면 한 문제, 큰 보기, 짧은 피드백, 다음 버튼 하나’를 중심으로 첫 화면과 퀴즈를 실제 V3로 개편했습니다. 기존 운영 주소에서 제공하며 공유 주소·QR·공유 문구는 바꾸지 않습니다.

## 바뀐 경험

- 첫 화면은 오늘 이어 할 이야기와 시작 버튼, 세 걸음의 배움길, 내 독도에 집중합니다. 기존 풍경·지도·도감·순위·학년·설정·기록은 더보기로 접근합니다. 이전 키의 기록 발견 안내는 기본 화면에 계속 표시합니다.
- 수업 중에는 큰 문제와 보기, 진행 표시, 짧은 정오답 설명을 보여줍니다. 자세한 설명과 출처는 펼쳐 볼 수 있으며, 정답 판단에 필요한 본문·맥락·필수 자료는 유지합니다. 원문·보기·정답·해설 데이터는 수정하지 않았습니다.
- 별명·학교 등 선택 정보는 접어 두고 기존 공개 안내도 함께 유지합니다. 나이대만 고르고 학습할 수 있습니다. 첫 문제가 연속해서 같지 않게 하고, 기존 문제·보기 무작위 순서도 유지합니다.
- 달리기는 라운드마다 잠깐 멈춰 결과를 보고 직접 다음을 시작합니다. 1~20라운드에서 속도·길이·장애물 조합이 점진적으로 달라지고, 21라운드 이후도 이어집니다. 장애물은 무작위 묶음으로 섞으며, 별은 1~2개와 서로 다른 높이로 배치됩니다. 짧게 누르면 낮게, 누르고 있으면 높게 뜁니다. 배경은 1.2초 디졸브이며 캐릭터와 장애물은 선명하게 유지합니다.
- 개인 최고 라운드·점수를 같은 브라우저에 저장합니다. 공개 순위표·다른 학생의 기록 집계는 추가하지 않았습니다.
- ‘독도 바다 청소’는 생수병·비닐봉지·빨대·찌그러진 일회용 컵·폐타이어·버려진 그물을 구분해 보여줍니다. 태극기와 생명은 쓰레기로 취급하지 않습니다.
