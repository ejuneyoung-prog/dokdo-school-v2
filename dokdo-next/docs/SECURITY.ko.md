# 보안·데이터 경계

이 패키지의 검증은 자체 검사이며 외부 독립 보안감사 완료가 아닙니다.

## 신뢰 경계
새 앱은 로컬 학습 도구입니다. 점수와 보상을 서버가 인증하는 대회 시스템이 아닙니다. 개발자 도구로 로컬 데이터를 바꾸는 행위를 공정한 서버 순위처럼 방어한다고 주장하지 않습니다. 새 저장 키는 소프트웨어 충돌 방지 수단이지 암호화나 같은 origin의 스크립트에 대한 접근 통제가 아닙니다.

## 하지 않는 것
운영 Apps Script URL 호출, 이름+4자리 번호로 클라우드 자료 조회, 학교별 공인 순위, 타인 프로필 검색을 하지 않습니다. 기존 서버 코드를 교체하지 않습니다. 실제 이용자 자료로 침투 시험을 하지 않았습니다.

## 방어한 것
사용자 별명은 textContent로 표시합니다. 임의 HTML로 삽입하지 않습니다. JSON은 eval하지 않고 크기/구조/지원 버전/위험한 키를 확인합니다. 학습/보상/봉화/방문시간을 잃는 백업은 자동 덮어쓰지 않습니다.
동시 쓰기는 지원 브라우저의 Web Locks와 저장 전 비교를 사용합니다. pagehide의 마지막 기록 보관은 최선의 노력이며 프로세스 종료까지 절대 보장을 하지 않습니다.
실제 서버 인증과 동시성 제어를 대체한 것이 아닙니다.

## 원문 보호
원래 두 학습 키를 읽을 수는 있으나 쓰거나 삭제하지 않습니다. 명시적 복사 전에 새 풍경을 보여 주고 원문 사본을 남깁니다. 손상된 새 저장 공간도 원문을 남긴 뒤 정상 백업으로 복구합니다. 기존 정상 사본과 다른 복구 사본이 있으면 덮지 않고 중단합니다.

## 공개 배포 전
구형 앱이 같은 origin에 계속 있다면 그 취약점도 검토해야 합니다. 구형 클라우드 보호가 끝나지 않은 상태에서 ‘모든 기록이 안전하다’고 공지하지 않습니다.
실제 이용자 JSON, 시트 사본, 계정 코드, 토큰을 GitHub 저장소에 올리지 않습니다.
독립 검토와 실기기 결과는 docs/VERIFICATION.ko.md의 자동 검사와 구분해 기록합니다.
