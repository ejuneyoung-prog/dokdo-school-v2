## 최종 변경

- 기존 GmarketSans Medium/Bold 선언을 유지하고 V3 본문과 조작 문구에도 적용한다. 주요 본문·설명·버튼·단계 이름은 기본 16px, 보조 상태는 14px로 정리했다. 아이콘과 정보 위계·간격·대비를 보완하고 주요 조작 영역은 44px 이상을 목표로 했다. rem 크기로 글자 확대에 반응한다.
- 33단계 전체를 유치원·초등, 중·고등, 대학, 석·박사, 독코민의 다섯 접이식 그룹으로 표시한다. 현재 단계가 있는 그룹을 기본으로 연다. 모바일은 짧은 카드 격자, PC는 폭에 맞는 여러 열이며 이름과 완료·현재·다음 상태를 글자로 표시한다. 현재 단계에는 aria-current=step을 둔다.
- 성취 배지는 아이콘·이름·획득/도전 상태를 구분하고, 긴 한영 이름과 확대 시 열 수가 줄어든다.
- 본부 인수 검수에서 PR32 account-entry.css의 후로드 규칙이 로그인 버튼 폭을 35vw로 다시 줄이고 닉네임을 자르는 충돌을 발견했다. 직계 헤더 자식에 더 구체적인 규칙을 적용해 줄바꿈과 가시 영역을 보장하고 모바일 전체 폭을 유지한다.
- 실제 CUA 화면 검수에서 더보기의 학년·명예의 전당은 내부 span의 기존 12px 규칙이 남는 것을 발견해 1rem으로 보완했다. 실제 DOM 재측정으로 16px를 확인했다.

제품 실행 변경은 assets/app.js의 renderGrade 표시 함수와 assets/school-v3.css다. 학습 문항·정답·진급 계산·점수·저장·로그인·음악·게임·CSP·API·공유 이미지/문구/QR은 변경하지 않았다. app.js의 renderGrade 앞뒤가 기준 main과 같은지 별도로 확인했다. 공개 기록지·Apps Script·OBS도 변경하지 않았다.
