# 독도 알아보기 · 독도 코리아 채널

확인일: 2026-10-19 (한국 시간)

기존 운영 주소 `https://dokdo-school-v2.vercel.app/dokdo-next/`와 메인의 독도 배움터·독도 놀이터 두 입구를 유지합니다. 학습 모델·기록 저장 키·문항·Apps Script·공유 주소·QR·공유 문구는 바꾸지 않습니다.

## 화면

- 메인 설명 아래 `실시간 독도 보러 가기 ↗`를 별도 버튼으로 표시합니다. 주소는 특정 방송 영상 ID가 아닌 `https://www.youtube.com/@독도코리아/live`입니다.
- 더보기의 큰 콘텐츠 입구는 `독도 알아보기`, `독도 코리아 채널` 두 개입니다. 기록·언어·설정·학년·명예의 전당·내 계정은 아래 작은 도구로 유지합니다.
- 독도 알아보기는 기존 독도 풍경, 시간·날씨, 지도·크기·시설, 생명 도감, 240문항과 자료 출처를 모읍니다. 기존 풍경의 학습 성취·봉화·방문 기능도 보존합니다.
- 채널 화면에는 최근 공개 영상, 고정 라이브 링크, 채널 소개, 기존 음원·SNS·협업·후원 링크를 모읍니다. 기존 레이블·음원 채널 링크는 변경하지 않습니다.
- 날씨는 기존 연결 확인 정책을 유지합니다. 이용 조건이 확인되지 않은 Open-Meteo 연결을 켜거나 실제 관측값을 만들어 표시하지 않습니다. 연결되지 않았거나 실패하면 해당 상태를 안내합니다.
- 메인에서는 인증 SDK·인증 요청을 실행하지 않습니다. `account-entry.js`는 내 계정 링크만 제공하며 실제 인증은 계정 페이지의 책임입니다.

## 실제 최근 영상의 근거

공식 채널: <https://www.youtube.com/@독도코리아>

공식 페이지의 `externalId`와 canonical 채널 주소를 조회해 `UCVfBrS1H2crOZHjf2I1mv0A`를 확인했습니다. 부모 작업자도 공식 채널 UI에서 같은 ID를 확인했습니다.

공식 공개 RSS: <https://www.youtube.com/feeds/videos.xml?channel_id=UCVfBrS1H2crOZHjf2I1mv0A>

구현 시 실제 RSS 및 새 서버 핸들러를 조회해 200 응답·6개 영상을 확인했습니다. 당시 첫 영상은 `rjjeZE_tPso`, 공개일은 `2026-10-18T12:50:58Z`, 다음 영상은 `oaSM6yjybL4`, 공개일은 `2026-10-16T10:00:17Z`였습니다. 이 목록을 고정 데이터로 넣지 않고 매번 공식 피드로 갱신합니다. 라이브 버튼은 이 영상 ID를 쓰지 않습니다.

YouTube RSS는 피드 맨 위 채널 ID에서만 `UC` 접두사를 생략하고 각 영상의 채널 ID에는 전체 ID를 사용했습니다. 이 실제 형식을 파서와 회귀검사에 반영했습니다. 영상의 소속 채널은 전체 ID가 정확히 일치해야 합니다.

## 서버와 실패 처리

루트의 `api/channel.js`는 Vercel Node 함수이며 `/api/channel`에서 동작합니다. Vercel 공식 문서의 프로젝트 루트 `api` 함수 배치를 따릅니다: <https://vercel.com/docs/functions/runtimes/node-js/advanced-node-configuration>.

- 비밀 키가 필요하지 않습니다. 요청에서 임의 URL이나 채널 ID를 받지 않고 위 공식 RSS 한 곳만 읽습니다.
- GET·HEAD만 허용합니다. 학생 데이터·학습 기록·계정 정보와 연결하지 않습니다.
- 중복 영상을 제거하고 공개일 역순으로 최대 6개를 반환합니다. 제목은 실행되는 HTML이 아닌 텍스트로만 화면에 표시합니다.
- 서버 메모리와 CDN 캐시는 확인 시점부터 최대 15분입니다. 이미 보관된 응답을 다시 반환할 때 CDN 유효기간을 남은 시간으로 줄여 캐시가 연장되지 않게 합니다.
- 채널 화면을 실제로 열 때만 요청합니다. 언어 전환은 이미 받은 목록을 다시 표시합니다. 미리보기에서는 API를 요청하지 않습니다.
- 실패·잘못된 피드는 503 상태와 실패 안내를 표시합니다. 예전 무작위 영상 풀이나 오래된 캐시를 최신 영상으로 대신 표시하지 않습니다. 다시 불러오기와 공식 채널 링크를 제공합니다.
- 발행일은 영상의 실제 공개일이며 목록 확인 시간은 한국 시간으로 별도 표시합니다. 썸네일을 누르면 새 창의 YouTube에서 봅니다. 자동 재생하지 않습니다.

## 검증

`tests/channel.test.cjs`: 공식 형식·채널 검증·제목 디코딩·정렬·중복 제거·6개 제한·고정 요청 주소·동시 요청 합치기·캐시 만료·오류 시 정직한 응답·GET/HEAD 제한을 검사합니다.

`tests/release-13-browser.py`: 메인 라이브 링크, 더보기 두 입구, 정보/채널 분리, 기존 지도·시설 보존, 가상 피드의 실패→재시도 성공, 언어 전환 시 재요청 방지, 학습 성취 불변, 미리보기의 피드 요청 차단을 검사합니다. 가상 피드 검사는 로컬 요청을 대체하며 실제 운영 기록이나 YouTube에 테스트 게시를 하지 않습니다.

정적 검사는 변경 당시 119개 통과, 공식 피드 API 검사 9개 통과입니다. 실제 Vercel 배포 후에는 `/api/channel`의 200 응답과 공식 목록 표시를 별도로 확인해야 합니다.
