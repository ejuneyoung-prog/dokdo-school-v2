## 이번에 실제로 완료한 범위
1. 기존 1.2의 실행 소스에 새 기능을 합쳤습니다. 예전 야경 캡처만 다시 포장한 것이 아닙니다.
2. 독도 좌표·한국 날짜 기준의 일출/일몰 계산과 낮·노을·밤의 명암 전환을 구현했습니다. 낮/노을/밤 미리보기는 실제 시간과 구분합니다.
3. 1,025칸 성장 경로를 연결했습니다. 동도 500, 서도 500, 주변 기념 지점 25입니다. 두 섬은 10칸씩 번갈아 채웁니다. 25를 실제 섬 개수로 표시하지 않습니다.
4. 노란 길을 완성하면 기존 길을 남긴 채 흰색으로, 다음에는 에메랄드색으로 성장합니다. 1,025에서 초기화하거나 1,030까지 더 풀게 하지 않습니다.
5. 태극기 표시와 경로는 화면 너비를 고려합니다. 좁은 화면에서는 깃발 일부를 묶어 보여주고 확대할 수 있습니다. 밤에는 빛을 강조하고 낮에는 길을 약하게 표시합니다.
6. 동도 시설의 수정된 투명 그림을 기존 배경과 합성했습니다. 헬기장 아래 경비대, 그 아래 등대가 보이는 수정 사본을 사용합니다. 화면과 기념사진은 같은 합성 결과를 사용합니다. 실측 지도라는 뜻은 아닙니다.
7. 강치는 새 호출당 1분, 최대 10마리이며 다른 화면/대화상자에서 관람 시간이 멈춥니다. 기존 호출권과 과거에 저장된 잔여시간은 깎지 않습니다.
8. 문항의 정답과 의미를 바꾸지 않고 역사 맥락을 보강했습니다. 작성 원본 대조 결과 **71문항의 배경이 바뀌었고, 240문항의 질문·보기·정답 ID는 유지**됐습니다. 중학생 배치고사는 갑작스러운 청의서 비교 대신 섬 비교에서 시작합니다. 일반 수업은 해당 역사 단원의 배경을 먼저 설명합니다.
9. 수토관=Sutogwan(섬 조사 관원), 유인등대=staffed lighthouse 등의 용어표를 추가했습니다. 현재 활성 영어 데이터에 Water pipe/Yoo in Lighthouse가 없음을 검사하고, 앱의 중복 자동번역을 억제하는 표시를 추가했습니다. 외부 톡 번역기나 구형 운영 페이지까지 수정했다는 뜻은 아닙니다.
10. Gmarket Sans는 제목·메뉴·주요 수치, S-Core Dream은 질문·보기·배경·해설에 지정했습니다. 저장 이미지도 동일한 글꼴을 요청하고 로드를 기다린 뒤 내보냅니다. 폰트 파일은 배포물에 넣지 않았습니다.
11. 날씨 API 연결, 30분 캐시, 재시도 제한, 요청 취소, 자료시각·단위·좌표·기상코드 검사, 지연/만료 안내를 구현했습니다. 이용조건 확인 전에는 요청하지 않는 상태로 전달합니다.

- 0/1/9/10/500/1,000/1,024/1,025/1,026/1,500/2,050/3,075/512,500의 경로 분배.

- 오래된 탭의 덮어쓰기, 일부 성취가 사라지는 백업 복원 거부.
- 손상된 원문을 별도로 남긴 뒤 명시적으로 백업을 복원하는 경로.
- 실제 Blob PNG 내보내기와 JSON 내보내기/파일 입력 복원.

- 단위/위치/시각이 잘못된 날씨 응답 거부.
- 새 시설 이미지를 로드한 캔버스와 저장 이미지의 같은 렌더 경로 사용.

## 실제로 검증하지 못한 것
이 환경에서는 로컬 HTTP 주소 접근이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단됐습니다.
실패 로그를 `test-results/v13/http-probe.log`에 남겼고 제한을 우회하지 않았습니다.

브라우저 검사는 실제 Chromium의 DOM·캔버스·미디어·다운로드를 실행하되 about:blank와 통제한 저장소를 사용했습니다.
실제 주소의 영속 저장·용량·완전한 동시성, 실제 iPhone/Android/Kakao, 물리 스피커, 휴대폰에서 1분 연속 사용과 발열은 미검증입니다.
GitHub Actions에 HTTP Chromium/WebKit 검사를 연결했으나, 원격 저장소에 업로드하거나 그 검사를 여기서 실행한 것은 아닙니다.

웹폰트 다운로드는 검사에서 차단했습니다. 결과 이미지는 대체 서체이며, 지정 서체의 최종 외형을 확인한 스크린샷으로 소개하지 않습니다.
날씨는 합성 응답과 실패 응답으로 검증했습니다. 실제 Open-Meteo 통신이 이 환경에서 성공한 것은 아닙니다.
일출/일몰은 SunCalc 1.9.0 태양 계산을 적용한 근삿값이며 관측·항해 자료가 아닙니다.

## 교육 및 번역 범위
현재 240문항·60개념을 유지했습니다. 원래 1,513문항 전수 재번역이나 전수 재작성은 아닙니다.
하루 500개의 서로 다른 새 문제/개념이 있다는 뜻도 아닙니다. 교육자료와 출제 규모 확대는 별도 작업입니다.
이전부터 남아 있는 읽기 길이 검토 5건은 자동으로 승인하지 않았습니다.
역사 자료의 국가·기관·시기·원문과 현대 해석의 구분은 기존 검수 규칙을 유지했습니다.
배경 설명 보강은 기존 공식 출처를 바탕으로 하며 이번에 모든 원문 전문을 독립 전문가가 다시 검증한 것은 아닙니다.
직원이 상주하는 등대의 영어는 staffed lighthouse라는 기존 공식 자료 표현을 용어표에 기록했습니다.
수토관 오역 제보의 구형 운영 원본/자동번역 경로는 실제 서버에서 확인하지 않았습니다.

## 기록 보존
1.3의 신규 경로 필드만 추가하고 기존 기록 ID·정답 수·점수·봉화·호출권은 유지합니다.
새 경로의 최초 기준값은 기존 기록의 누적 정답 또는 불빛에서 가져옵니다. 새 인정 규칙으로 소급 재검증한 점수라는 뜻은 아닙니다.
기존 1.2용 백업을 더 진행한 1.3 기록에 무조건 덮어쓰지 않습니다. 경로 손실이 있으면 차단합니다.
아무 성취가 없는 새 프로필에 기존 백업을 가져오는 것은 허용합니다.
새 코드에서 쌓인 기록을 버리는 롤백을 하지 마세요. 먼저 전체 JSON 백업과 기존 운영 코드 사본을 보관합니다.
구형 이름+4자리 코드 기반 클라우드와 실제 서버는 변경하지 않았습니다.
