## 1. 문제 정의

독도 문제는 **독도에 관한 한 가지 사실·명칭·관계·판단을 분명하게 묻고, 답을 고른 뒤 그 답의 이유와 독도 지식 하나를 가져가게 하는 질문**입니다.

질문의 출처 머리말은 없애고 출처를 보기 아래에 별도로 표시했습니다. 국가·역사 기관·시기·대상은 의미를 결정할 때 질문과 배경에 명시합니다. 자료가 필요하면 문제마다 표시하며, 낮은 난이도라고 자료를 일괄 삭제하지 않습니다. 각각의 보기에는 정답·오답의 이유가 연결됩니다.

- 현재 출제 240문항의 한국어·영어 쌍을 새로 작성했습니다. 번역본을 합쳐 480문항이라고 부풀려 세지 않습니다.

## 3. 고친 생성·실행 구조

실행 원본은 `tools/content/authored-questions.json`입니다. 이전 생성기는 archive/generator-v2에 남기고, 새 `build_course.py`는 작성 문안을 변환·검증하는 역할만 합니다. 빠진 해설을 공통 사실문으로 채우지 않습니다.

정답·보기별 해설·출처·근거 위치·자료 필수 조건·회수 ID를 검사합니다. 새 코드가 실행 중인 모든 보기의 고유 ID와 해당 해설을 같이 섞습니다. UI는 자료·짧은 배경·질문·보기·출처·선택한 보기의 설명·남길 한 문장을 구분합니다.

`data/course-v2.json`은 경로 호환을 위해 유지한 파일명입니다. 내부 버전과 내용은 `2026-09-12-course-v3-clear`입니다. JSON 생성물만 수동 수정하면 다음 빌드와 어긋나므로, 원본을 수정한 뒤 `python tools/content/build_course.py --check`까지 실행해야 합니다.

## 4. 역사·국가·자료 범위

태정관지령의 원문 작성 기관은 1877년 일본 태정관이고, 현대의 역문·지명 해설 공개 기관은 대한민국 외교부입니다. 1696년 금지령 질문은 원문에 명시된 울릉도 도항을 대상으로 합니다. 독도의 역사와의 연관성을 부정하는 것이 아니라 문서의 대상과 사료의 의미를 구분합니다.

대한민국 외교부가 설명하는 태정관지령과 기죽도약도의 영유권 근거로서의 의미는 해설에 남겼습니다. 이를 국제재판 판결이나 오늘날 일본 정부의 성명으로 바꾸지 않습니다. 기후 출처의 지역 범위는 독도를 포함한 울릉도 부근지역으로 명시하고, 오래된 수치를 오늘의 예보라고 쓰지 않습니다.

출처30개는 본문 또는 공식 검색 색인·기존 공식 발췌로 비교했습니다. 일부11개 출처는 직접 전문 접속이 제한되어 공식 색인을 이용했고 이를 `source-registry.json`의 `verificationAccess`와 `course-audit.json`에 표시했습니다. 30개 모두 원문 전문을 독립 전문가가 검증했다는 뜻이 아닙니다.

## 5. 난이도와 인지 활동

네 번째 변형이라는 이유로 L4를 부여하던 방식을 없앴습니다. 난이도와 실제로 요구하는 인지 활동은 별도 필드입니다. 작성자 재분류 결과는 L1 69개, L2 52개, L3 104개, L4 15개입니다. 이 분류는 실측 난이도·교육효과·독립 교사 판정이 아닙니다.

초등저와 중학년 경로는 서로 다른 배분을 사용합니다. 학년별 글자수는 참고 경고로만 쓰고, 주체·대상·시기를 삭제하여 억지로 숫자를 맞추지 않습니다. 길이 검토 항목은 추가 교정 후30건에서5건으로 줄었으며, 5건은 Excel의 읽기점검 시트에 남겼습니다. 자료를 포함한 실제 읽기 부담은 학습자 관찰이 필요합니다.

## 7. 실행 환경·미검증

현재 환경에서 native localhost 접속을 시도했으나 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되었습니다. 우회하지 않았고 `evidence/http-probe.log`를 남겼습니다. 실제 Chromium DOM/캔버스/파일을 실행했으며, 기록 저장소는 통제된 메모리 대역입니다. 전체 문항 표시 검사는 풍경 애니메이션을 일시 정지하여 문항 동작에 집중했고, 실제 화면/흐름 검사는 원래 프레임 루프와 모션 감소 설정에서 실행했습니다.

실제 주소에서의 저장 유지·용량·동시성, 실제 iPhone/Android/Kakao, 물리 스피커, 운영 계정·구형 시트 이관은 검증하지 않았습니다. CI에 실제 HTTP Chromium/WebKit 실행을 연결했으나 원격 GitHub Actions를 여기서 실행한 것은 아닙니다.

글꼴 다운로드는 테스트에서 차단했습니다. 화면 캡처는 대체 글꼴입니다. 서체 파일은 배포물에 포함하지 않습니다.

Excel의 9개 시트는 openpyxl로 작성했고259개 단순 계산식을 독립 계산해 OOXML 캐시에 반영·재확인했습니다. 설치된 통합 렌더 서비스가 시작하지 못해 셀 내용 미리보기를 대신 확인했습니다. 이를 실제 Excel 앱의 렌더 검증이라고 표시하지 않습니다.

같은 작성자가 원자료 비교·문항 교정·반례를 수행했습니다. 별도 교사나 역사전문가·독립 레드팀의 승인은 받지 않았습니다. 학생의 이해도 검사를 자동화 수치로 대체하지 않습니다.
