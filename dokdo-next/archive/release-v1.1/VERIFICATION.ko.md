## 5. 검사 중 발견하고 고친 문제
날짜형식만 맞고 존재하지 않는 날짜가 저장되는 문제를 막았습니다. 배치고사 답이 실제 성취로 지급되지 않게 분리했고, 같은 개념의 서로 다른 보기로 당일 보상이 여러 번 나오는 것을 막았습니다. 도움말을 연 복습은 독립 숙달로 세지 않습니다. 오답 뒤 직접 함수를 호출해도 다음 문제로 넘기지 못합니다.

완료 단원의 문항을 위조된 개념/단원 정보로 제출하는 경로를 실제 활성 문항ID로 재확인합니다. 완료/숙달 정보가 빠진 백업을 거부합니다. 원래1,513개+옛48개 기록을 넣어 새 수업을 마쳐도 기존 개별 기록이 바뀌지 않는 것을 비교했습니다.

화면 이동 확인창을 취소했는데 지도 상태만 바뀌던 문제를 재현해 수정했습니다. 취소하면 문제 화면과 지도 상태를 모두 보존합니다. 언어를 바꿔도 학습경로 이름이 한국어로 남던 문제를 고쳤습니다. 일부 검사는 새보기3개/새문항ID와 맞지 않는 오래된 기대값이어서 명세에 맞게 갱신했습니다. 과거 실패를 통과 수에 합산하지 않았습니다.

## 6. 지도 범위
기존 홈의 승인 일러스트는 유지하며 불빛/봉화 좌표를 바꾸지 않았습니다. 지도 보기에는 공식 윤곽을 단순화한 형태와 동도/서도의 상대적 특징을 설명하는 자체 구조도를 넣었습니다. 동도는 낮고 넓은 상부, 서도는 가파른 주봉으로 구분합니다. 구조도는 측량한3D지형/고도모델/실제바위·시설좌표가 아닙니다. 사진처럼 사실적인 새조감도를 완성했다는 주장은 하지 않습니다. 기존감상그림을 실측지도라고 사용하지 않도록 두 모드를 분리했습니다.

## 7. 분명한 미검증 범위
Chromium DOM/캔버스/미디어/Blob파일을 실행했습니다. 다만 native localhost 탐색이 ERR_BLOCKED_BY_ADMINISTRATOR로 차단돼 저장소는 통제한 대역으로 시험했습니다. 제약을 우회하지 않았습니다. 실제 origin 저장 지속성·기기 용량·다중프로세스 원자성, 실제 iPhone/Android/Kakao, 물리 스피커, 실사용1분 관람은 미검증입니다. HTTP실주소 Chromium/WebKit 검사는 CI파일에 있지만 원격 실행하지 않았습니다.

실제 계정/운영시트/클라우드자료를 읽거나 이관하지 않았습니다. 콘텐츠는 출처 기반 자체 검토이며 독립 교사/내용전문가 검수나 국가 교육과정 인증이 아닙니다. 같은 작성자의 반례 검사는 독립 감사를 대체하지 않습니다. 공개 확대 전에는 이 영역의 확인이 필요합니다.
